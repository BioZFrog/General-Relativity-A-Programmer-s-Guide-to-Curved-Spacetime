# General Relativity: A Programmer's Guide to Curved Spacetime 🌌

Welcome! This is an open-source, living textbook tracking my journey into the deep end of Einsteinian physics, differential geometry, and tensor calculus. 

## 🧠 About This Project
Most physics textbooks wrap General Relativity in dense academic jargon. As a 15-year-old programmer, I am writing this book to demystify these complex spatial structures using logical, step-by-step algorithms and algorithmic analogies that make sense to developers.

## 🚀 How to Read
Simply download or view the `General_Relativity_Draft.pdf` file in this repository. I actively recompile the PDF as I learn and master fresh concepts. 

*Please note that I am not a general relativist, and that I may have made some mathematical, logical, or factual mistakes in the textbook. So feel free to open an Issue if you spot a math typo or a conceptual misconception!*
